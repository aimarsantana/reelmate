# analysis/ (Phase 2)

Data-science side of Reelmate: notebooks and scripts in Python.
In Phase 1 this folder is only a placeholder. Phase 2 will add a model that predicts
the rating you would give to a film, trained on your Letterboxd data enriched with TMDB.

Parte de ciencia de datos de Reelmate. En la fase 1 solo es un marcador de sitio; en la fase 2 llegará el modelo que predice qué nota le pondrías a una película.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```
